# Statement of Intent: أَثَر (Athar) v1

- **Outcome:** A polished, smooth, standalone Android app (with a proper custom logo and real mobile UI, not a web wrapper) for searching hadiths by any Arabic word (beginning, middle, or end) via **Al-Dorar (الدرر السنية)**, with clear color-coded authenticity badges, forgiving Arabic search (handling diacritics and light typos like `النارر` / `الناور` → `النار`), simple grade filtering (e.g., Sahih only), and clean Copy/Share actions.
- **User:** Starting with the creator and people around them via APK, built cleanly to eventually serve Muslims everywhere across all kinds of Android phones.
- **Why now:** The current **الباحث الحديثي** Android app feels like a basic web wrapper with an unpolished logo and cramped UX; the goal is a genuinely smooth, eye-friendly alternative that works reliably on any Android phone.
- **Success:** Anyone installs the APK on Android 16, 15, 14, or older Android phones (small or large screens), types any Arabic word (even with small spelling slips), effortlessly scans crisp hadith cards showing the Sahabi, Matn (with the matched word highlighted), source, and unmistakable Sahih/Hasan/Da'if status, filters to **Sahih only** in one tap, and copies/shares any hadith cleanly — with zero UI clipping or visual clutter.
- **Constraint:** Keep v1 strictly focused on nailing the core search-and-reading experience without feature bloat; use **Al-Dorar** online for v1; keep the UI coherent in both **Arabic (primary, RTL)** and **English (LTR)**; support broad Android versions (**Android 16, 15, 14, and older**) with proper edge-to-edge safe areas and responsive layouts.
- **Out of scope (for v1 — saved for v2):** The second data source with the full narrator chain (**Sanad ON/OFF** leaving only the Sahabi), offline mode, narrator biographies/isnad trees, accounts, Play Store publishing, and heavy extra features.
